システム概要・セキュリティ開示

気象神社 システム構成図 ({% if ai_provider == 'nvidia' %}NVIDIA版{% else %}Gemini版{% endif %})

[ フロントエンド ]
HTML5 / Vanilla JS / CSS3 (レスポンシブ対応)
※すべてサーバーサイドレンダリング(Jinja2)で提供。

[ バックエンド (Flask) ]
・Meteoblue API: {{ location }} のピンポイント気象履歴・予報(14日間)を取得
{% if ai_provider == 'nvidia' %} ・NVIDIA NIM API (Parallel): deepseek-v3.2 と gpt-oss-120b を専用プロセスで完全並行稼働。制限なく神託・御守りを常時生成し続けます。
・API Key 分散: レートリミット回避のため、機能ごと（お賽銭、神託、御守り、チャット）に独立したAPIキーとOpenAIクライアントを割り当てています。
{% else %} ・Google Gemini API: 気象データ・気象学に基づいた神託文書の動的生成
{% endif %} ・gTTS: 生成されたテキストをローカルで音声合成・保存(API通信なし)
{% if ai_provider == 'nvidia' %} ・JSON永続化 (RLock制御): 複数モデルが同時に content_nvidia.json にアクセスしても競合しないよう、スレッドロックを用いて安全に保存・再利用します。 {% else %} ・JSON永続化: 生成した神託・御守りは content.json に記録・再利用 {% endif %}

[ ネットワーク & セキュリティ ]
当システムは自身のPC(ローカル環境)で動作し、Cloudflare Tunnel を経由して安全に外部へ公開されています。

🔒 APIキー保護機構:
すべてのAPIキーは .env ファイル(環境変数)としてサーバーPC内でのみ保持され、バックエンドプロセス(Python)からのみアクセスされます。
ブラウザ(フロントエンド)には一切送信されないため、第三者がブラウザのソースコードや通信履歴からAPIキーを抜き取ることは物理的に不可能な設計です。
